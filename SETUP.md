# SchemeConnect Setup

## Clone

```bash
git clone https://github.com/Rubai106/SchemeConnect.git
cd SchemeConnect
```

## Install

```bash
npm install
```

## Create .env

Create a `.env` file:

```env
PORT=5000
MONGODB_URI=<provided by project owner>
```

## Run

```bash

npm run dev
```

Server:

```
http://localhost:5000
```
